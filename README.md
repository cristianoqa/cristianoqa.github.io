# Flow Home Apps

Landing pública: https://cristianoqa.github.io/

La portada (`index.html`) es un catálogo en cuadrícula con filtro por plataforma (Todas, iPhone / iOS, Android, Para negocios) e idiomas ES, EN y PT-BR. Los estilos de Tailwind están compilados en `assets/landing.css`.

Políticas de privacidad: https://cristianoqa.github.io/policies/

Si cambias clases en `index.html`, recompila los estilos:

```
npm run build:css
```
